# VPN-магазин: сайт + Telegram-бот

Один сервер обслуживает и сайт, и бота. База — один файл `data/shop.db`.

## Запуск на Mac (проверка, 5 минут)

1. Распакуйте архив, дважды щёлкните `start-mac.command`.
   Если Mac не даёт открыть: правый клик -> «Открыть».
2. Откроется файл `.env`. Впишите `BOT_TOKEN` (получить: Telegram -> @BotFather -> `/newbot`)
   и сохраните. Закройте окно Терминала и запустите `start-mac.command` ещё раз.
3. Сайт откроется на http://localhost:8000, бот начнёт отвечать в Telegram.

По умолчанию включён демо-режим (`DEMO=1`, `PANEL=mock`): оплата USDT понарошку,
ключи ненастоящие. Так можно пройти весь путь покупки без денег и без VPN-сервера.
Оплата звёздами в демо скрыта: звёзды списались бы по-настоящему. Она появляется,
когда подключена настоящая панель (`PANEL=marzban`).

Защита от ошибки: если выключить демо (`DEMO=0`), но не подключить панель (`PANEL=mock`),
продажи закрываются сами — бот не возьмёт деньги за ненастоящий ключ.

## Что нужно для настоящих продаж

| Что | Где взять | Куда вписать в `.env` |
|---|---|---|
| Приём USDT | @CryptoBot -> Crypto Pay -> Создать приложение | `CRYPTOPAY_TOKEN` |
| VPN-сервер | VPS за границей + панель Marzban | `PANEL=marzban`, `MARZBAN_URL`, `MARZBAN_USER`, `MARZBAN_PASS` |
| Выключить демо | — | `DEMO=0` |
| Уведомления, бэкапы, админ-команды | @userinfobot покажет ваш ID | `ADMIN_ID` |
| Контакт поддержки | ваш @username | `SUPPORT` |

Уведомления об оплате: в настройках приложения Crypto Pay включите Webhooks и укажите
`https://ВАШ_АДРЕС/webhooks/cryptopay`. Без этого тоже работает: сервер сам проверяет
оплату раз в минуту.

## Запуск на сервере

```
cp .env.example .env      # заполнить, в том числе DOMAIN и SITE_URL=https://DOMAIN
docker compose up -d --build
```

Проверка, что сервер жив: `https://ВАШ_АДРЕС/api/health`. Этот адрес можно поставить
в бесплатный UptimeRobot — он напишет, если сервер упадёт.

Сайт на Cloudflare Pages: выложите папку `site`, в `site/config.js` впишите адрес сервера,
а в `.env` на сервере — `SITE_URL=https://ваш.pages.dev`.

## Тарифы

Начальный список — в `app/db.py` (`DEFAULT_PLANS`), цена за одно устройство.
Потом цены меняются прямо в боте: `/plans` и `/price`.

## Команды владельца в боте

Работают, только если в `.env` указан ваш `ADMIN_ID`. Полный список — `/admin`.

- `/stats` — клиенты, ключи, заказы, выручка за 30 дней
- `/plans`, `/price 1 2.5 200` — посмотреть и поменять цены
- `/retry 12` — выдать ключ по оплаченному заказу, если в момент оплаты панель была недоступна
- `/refund 12` — вернуть звёзды и отключить ключи заказа (USDT — вручную в @CryptoBot)
- `/send текст` — сообщение всем клиентам
- `/backup` — копия базы. Она и так приходит вам раз в сутки — не удаляйте эти сообщения,
  это ваша страховка, если сервер пропадёт.

Ещё бот сам пишет владельцу о каждой продаже и о заказах, где ключ не выдался.

## Вход на сайт

Кнопка «Войти через Telegram» открывает бота, и он спрашивает «Войти на сайт?».
Подтверждать нужно кнопкой — так чужая ссылка не откроет кому-то ваш кабинет.
