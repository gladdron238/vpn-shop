# VPN-магазин: сайт + Telegram-бот

Один сервер обслуживает и сайт, и бота. База — один файл `data/shop.db`.

## Запуск на Mac (проверка, 5 минут)

1. Распакуйте архив, дважды щёлкните `start-mac.command`.
   Если Mac не даёт открыть: правый клик -> «Открыть».
2. Откроется файл `.env`. Впишите `BOT_TOKEN` (получить: Telegram -> @BotFather -> `/newbot`)
   и сохраните. Закройте окно Терминала и запустите `start-mac.command` ещё раз.
3. Сайт откроется на http://localhost:8000, бот начнёт отвечать в Telegram.

По умолчанию включён демо-режим (`DEMO=1`, `PANEL=mock`): оплата USDT понарошку,
ключи ненастоящие. Так можно пройти весь путь покупки без денег и без VPN-сервера.
Оплата звёздами в боте работает по-настоящему даже в демо — не платите ими при проверке.

## Что нужно для настоящих продаж

| Что | Где взять | Куда вписать в `.env` |
|---|---|---|
| Приём USDT | @CryptoBot -> Crypto Pay -> Создать приложение | `CRYPTOPAY_TOKEN` |
| VPN-сервер | VPS за границей + панель Marzban | `PANEL=marzban`, `MARZBAN_URL`, `MARZBAN_USER`, `MARZBAN_PASS` |
| Выключить демо | — | `DEMO=0` |

Уведомления об оплате: в настройках приложения Crypto Pay включите Webhooks и укажите
`https://ВАШ_АДРЕС/webhooks/cryptopay`. Без этого тоже работает: сервер сам проверяет
оплату раз в минуту.

## Запуск на сервере

```
cp .env.example .env      # заполнить, добавить строку DOMAIN=myvpn.duckdns.org
docker compose up -d --build
```

Сайт на Cloudflare Pages: выложите папку `site`, в `site/config.js` впишите адрес сервера,
а в `.env` на сервере — `SITE_URL=https://ваш.pages.dev`.

## Тарифы

Список — в `app/db.py` (`DEFAULT_PLANS`), цена за одно устройство. Менять до первого запуска.

## Команды владельца в боте

- `/stats` — клиенты, ключи, заказы
- `/retry 12` — выдать ключ по оплаченному заказу, если в момент оплаты панель была недоступна
